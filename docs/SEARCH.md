# 全局搜索

控制台右上角“搜索资料”或 Ctrl/Cmd+K 打开搜索。输入名称、ASN、IP、MAC、AS-SET 或邮箱后查询当前可访问的数据；可选择类型缩小范围。结果可用上下方向键与 Enter 打开，目标页面定位到具体记录。重复打开当前地址也会重新定位；不会自动进入审批、生成或发布操作。

搜索覆盖可读库存、成员接入、联系人、备注、标签、配线、文档/目录元数据、核心互联、配置规则、sFlow 接收器和已授权的学习 MAC。文档正文、密码、token、BGP/SNMP 凭据及原始设备描述不进入索引。各领域使用显式字段白名单及原有读取权限；搜索不会因为某条数据能命中词语就放宽访问范围。

成员使用当前所选组织，只能搜索自己的资料、允许展示的标签/备注、文件及接收器；内部字段不参与匹配、摘要、计数或分页版本。用户账号搜索仅管理员浏览器可用。API token 分别需要 `resources:read`、`documents:read`、`core:read`、`provisioning:read`、`sflow:read` 或 `devices:read`，各scope只开放对应领域，没有通用万能搜索权限。学习MAC另受当前交换机绑定限制。会话撤销、组织切换或权限变化后会重新检查访问权。

`GET /api/search?q=...&types=members,connections&limit=20&cursor=...` 返回分组结果、可见匹配总数、下一页cursor和可见投影版本。cursor绑定查询及当前权限，不能更改query后复用或交给另一会话。可见数据改变时返回409并要求重新搜索；隐藏字段变化不会让成员获得变化信号。响应禁止缓存。

查询支持2–128个Unicode字符、最多8词、每词最多64字符；每页1–100条。候选索引最多20000条、32MiB，单字段64KiB。超出上限会明确要求按类型或交换机缩小范围，不返回假完整结果。学习MAC默认仅参与MAC查询；按普通文字查学习记录时选择 `types=learned-macs`，可加 `switchId`。设备文件读取最多128个交换机、32MiB。

保留的专用语法包括 `AS64501` 或纯ASN、规范或紧凑MAC、完整IP、`.10` 的IPv4末字节、`:abcd` 的IPv6末段、`AS-EXAMPLE`、`@账号`、`PPP-旧端口ID` 和 `xc:电路编号`。旧标识只有存在可验证的新记录映射时才命中，不按位置猜测关联。普通文字多个词要求每个词都出现在该记录允许搜索的字段中。

搜索是当前授权元数据的读取入口，不是旧审计日志或文件正文的全文索引。旧日志迁移和系统健康诊断仍由各自迁移项跟踪。
